# Python Examples 🐍

Ejemplos sencillos de Python para practicar y entender los conceptos básicos del lenguaje.

## Contenido

Actualmente el repositorio cuenta con ejemplos sobre:

- Variables y tipos de datos
- Operadores matemáticos

La idea es ir agregando más ejemplos de Python conforme avance el contenido.

## ¿Para quién es?

Principalmente para personas que están empezando con Python y quieren ver ejemplos simples de cómo funcionan algunas cosas del lenguaje.

Puedes clonar el repositorio y ejecutar los archivos `.py` directamente con Python.
